# Illustration brief

**The brief now lives in [`illustration-kit/README.md`](../illustration-kit/README.md).**

That directory is self-contained and is what gets handed to whoever generates
the illustrations: the full spec, the style reference, and 29 product renders
pulled from the live shop, with filenames prefixed by the slot they serve.

Kept as a pointer rather than a copy, so there is one place to change when a
slot moves.

## Summary

| | |
| --- | --- |
| Required | 14 (7 homepage, 7 training section) |
| Optional | 7 (4 procedure steps, 3 material macros) |
| Product renders supplied | 29 |
| Grounds | deep blue for the 2 hero slots, near-white for the rest |
| Untouched | the 8 photographs in `public/products/` stay photographs |

Two things worth knowing without opening the kit:

- **The spinal slots have no product behind them.** A04 and B11 show pedicle
  screws and a cage, but the Спінальна хірургія category on palarmus.com.ua is
  empty. That hardware has to stay generic until there is a SKU.
- **Each illustration is tied to a named SKU** from the live shop, so the art
  and the catalogue cannot drift apart. Named systems include NAVY A/R, NITE
  and NUNA nails, the Apex™ 3D TF trabecular cup, the Mirai™ PS knee, and the
  ParaTak™, LocTak™, SutureLoc™, XtraLoc™ PEEK and SpeedLoc™ anchors.
