# №42 — NAVY A/R, интрамедуллярный бедренный стержень 11 × 360 мм

Размерный ряд: `Прайс-лист Palarmus (остеосинтез) (2026).pdf`, стр. 12 — Ø10/11/12 × 300–400 мм.
Форма — по рендеру `42 Нави стегновий стрижень.jpeg` и послеоперационным рентгенам в
`3Д скелет/Травматологія/NAVY …`: передний изгиб, три цветных блокирующих винта на одном конце,
два раскрывающихся изогнутых крыла («якорь») на другом.
