# K3 — iU™ одномыщелковый эндопротез коленного сустава (CR, цементный)

iKey Medical, фиксированный вкладыш, с сохранением крестообразных связок. Источники: рендер
`source/Ендопротезування/Ендопротез одновиростковий колінного суглоба.png`, каталог стр. 8
(`pdf_pages/endo_08.png`: размерный ряд и второй ракурс).

**Размеры условные.** В каталоге ряд дан без миллиметров (компоненты 1#–7# LM/RL, RM/LL; вкладыш
7–11 мм), поэтому взяты типичные для среднего размера фиксированного uni-колена: полоз шириной 20 мм
и длиной ~50 мм, D-образная платформа 26,5 × 50 мм, вкладыш 8 мм. Когда появятся CAD или размерная
таблица iKey, меняются константы в `uni_params.py`.

## Файлы (`dist/`)

| Файл | Треуг. LOD0 / LOD1 | Вес LOD0 / LOD1 |
| --- | --- | --- |
| `femoral_iu_*` — бедренный компонент (полоз) | 18 468 / 5 828 | 232 / 105 КБ |
| `insert_iu_*` — вкладыш 8 мм | 12 760 / 3 916 | 103 / 41 КБ |
| `tray_iu_*` — большеберцовая платформа с килем | 13 752 / 3 536 | 141 / 65 КБ |
| **`uka_iu_*`** — сборка в разгибании | 41 370 / 12 244 | 406 / 167 КБ |

Сборка: узлы `tray`, `insert`, `femoral`. Система координат большеберцовая: нижняя сторона платформы
на 0, +Y вверх (glTF), метры; +X glTF — к межмыщелковому возвышению (прямая сторона платформы).
Нижняя сторона вкладыша в сборке удалена.

Материалы: `cocr_polished` (суставная поверхность, верх и борт платформы), `metal_beadblast` (сторона
кости: цементный карман, плавник, штифт, низ платформы, киль), `uhmwpe` (вкладыш). На рендере
производителя вкладыш бежевый — это цвет рендера, полиэтилен белый, как у K1.

## Как построено

Сборка повторяет K1 (`build_blender.py` выведен из него).

| Поверхность | Метод |
| --- | --- |
| Наружная поверхность полоза | **одно протяжённое SDF-поле**: выпуклый корональный профиль (R 22) вдоль сплайновой J-кривой; к переднему концу и к верху заднего мыщелка полоз сужается |
| Сторона кости | 4 плоскости опила (дистальный, задний, две фаски), карман 0,8 мм с бортиком 2 мм |
| Плавник и штифт | SDF: плавник 3 мм толщиной стоит на 8 мм в кость, со скошенным задним углом; штифт Ø6 |
| Граница полировка / пескоструй | разрез меша по плоскостям опила, смещённым на 1 мм (`split_by_planes`) |
| Платформа | профиль с бортиком, протянутый вдоль D-контура (`swept_outline`) + плоские крышки |
| Киль | трапеция в сагиттальной плоскости, нормализованное поле, рёбра скруглены на 1 мм (≥ двух шагов ремеша 0,4 мм; при 0,6 мм на скошенных рёбрах была «пила») |
| Вкладыш | SDF: D-контур внутри борта, почти плоская чаша (R 38 / 80), скруглённый верхний край |

`./build.sh` — полная пересборка (~1,5 мин).

## Ограничения
- Размеры условные (см. выше).
- Замка вкладыша в платформе нет: в сборке он не виден.
- Показан один вкладыш (8 мм) и одна сторона; другая сторона — зеркало по X.
