# H8 — ревизионная ножка Revistem™ M

Модульная ревизионная бедренная ножка: проксимальная часть **20×70** с плазменным напылением и дистальная
часть с рёбрами **16×190**. Средний типоразмер линейки.

| | |
| --- | --- |
| Размеры (каталог) | проксимальная 20×60 / 70 / 80, офсет 40, шейка 47, Ø20; дистальная 13–20 × 150 / 190, рёбра 1.2 мм, дистальный Ø 7.9–15 |
| Принято условно (по рендеру) | CCD 135°, 8 рёбер, полированное кольцо-замок на стыке, напыление до 18 мм ниже плеча, дистальный Ø на кончике 10.9 (линейная интерполяция по каталогу) |
| Конус | 12/14, тот же профиль, что у DeltaWay: подходят головки из `../hip-system` |
| Материалы | `ti_polished` (плечо, шейка, кольцо, конус), `ti_plasma_spray` (тело), `ti_satin` (дистальная часть, штрихи вдоль ножки) |

## Файлы (`dist/`)

| Файл | Треуг. LOD0 / LOD1 | Вес LOD0 / LOD1 |
| --- | --- | --- |
| `revistem_m_20x70_16x190_*` | 33 160 / 9 728 | 409 / 126 КБ |

Система координат как у DeltaWay: начало в центре головки, метры, ось ножки — glTF Y. Поэтому ножка
подставляется в сборки `../hip-system` (`revision_*`, `revision_tf_*`).

## Как построено

| Поверхность | Метод |
| --- | --- |
| Дистальная часть | `swept`: на каждом ребре свой столбец-гребень (острое ребро), желобки вогнутые, рёбра сходят на нет над пулевидным кончиком; точки кончика расставлены по углу дуги |
| Кольцо-замок | `lathe`, закрывает верхний торец дистальной части |
| Тело с напылением | `lathe` со ступеньками 0.5 мм на обеих кромках |
| Плечо и шейка | SDF → ремеш, срез плоскостью на 0.6 мм под кромкой напыления. Шейка — круглый усечённый конус с точным полем расстояния: сопряжение с телом даёт одну чистую седловину |
| Конус 12/14 | `lathe` (профиль H1) |

`./build.sh` пересобирает модель. Размеры в `revistem_params.py`: другой типоразмер — смена `LD`, `R_TOP`,
`R_TIP`, `L_PROX`.

## Ограничения
- Форма плеча и угол шейки сняты с рендера 450 px. Чертежа нет; CAD от производителя даст точную форму.
- Модульный стык (конус дистальной части внутри проксимальной) не моделируется: снаружи его не видно.
