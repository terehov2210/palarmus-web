# K1 — Mirai™ PS, тотальный эндопротез коленного сустава

iKey Medical, задне-стабилизированный (PS). Источники: рендер
`source/Ендопротезування/Ендопротез колінного суглобу зі стемом.png`, каталог (стр. 9: бедренный
компонент, тибиальная платформа, PS-вкладыш, стем), видео техники Mirai (Drive, использовано только
для контекста).

**Размеры условные.** В каталоге размерный ряд дан без миллиметров (1#–7#, LM/RM), поэтому взяты
типичные для среднего размера PS-системы: бедренный компонент ~66 × 62 мм, платформа 70 × 46 мм.
Когда появятся CAD или размерная таблица iKey, меняются константы в `knee_params.py`.

## Файлы (`dist/`)

| Файл | Треуг. LOD0 / LOD1 | Вес LOD0 / LOD1 |
| --- | --- | --- |
| `femoral_mirai_*` — бедренный компонент | 39 244 / 13 844 | 388 / 182 КБ |
| `insert_mirai_ps_*` — PS-вкладыш | 19 540 / 5 736 | 156 / 58 КБ |
| `tray_mirai_*` — тибиальная платформа с килем | 13 676 / 4 954 | 160 / 82 КБ |
| **`tka_mirai_*`** — сборка в разгибании | 67 316 / 23 074 | 627 / 275 КБ |

Сборка: узлы `tray`, `insert`, `femoral`. Система координат большеберцовая: нижняя сторона платформы
на 0, +Y вверх (glTF), метры. Нижняя сторона вкладыша (лежит на платформе) удалена.

Материалы: `cocr_polished` (суставная поверхность, верх платформы), `metal_beadblast` (сторона кости:
цементные карманы, бокс, пеги, низ платформы, киль), `uhmwpe` (вкладыш).

## Как построено

| Поверхность | Метод |
| --- | --- |
| Наружная (суставная) поверхность бедренного компонента | **одно протяжённое SDF-поле**: корональный профиль (два гребня с бороздой) вдоль сплайновой J-кривой |
| Сторона кости, PS-бокс с кулачком, пеги, карманы | SDF: 5 плоскостей опила, вычитания и объединения |
| Граница полировка / пескоструй | разрез меша по плоскостям опила, смещённым на 1 мм (`split_by_planes`) |
| Кромка платформы с бортиком | протяжка профиля вдоль контура (`swept_outline`) + плоские крышки |
| Киль с крыльями | SDF, срезан плоскостью нижней стороны платформы |
| Вкладыш (чаши, губа, стойка) | SDF, скругления не меньше двух шагов сетки |

`./build.sh` — полная пересборка.

## Ограничения
- Размеры условные (см. выше).
- Цементные карманы сделаны с пологой стенкой: ступенька 0.8 мм при веб-плотности сетки дробится.
- Фиксирующего механизма вкладыша в платформе (замок) нет: в сборке он не виден.
- Стем (K2) и одномыщелковый эндопротез (K3) — следующие модели на этой же основе.
