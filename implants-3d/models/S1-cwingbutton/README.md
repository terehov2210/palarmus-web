# S1 — C-WingButton™ 2, фиксация дистального межберцового синдесмоза (установленная)

iKey Medical, безузловая система. Размеры: `Титанова пластина для відновлення дистального … синдесмозу.pdf`
(стр. 2) и каталог спорт-травмы: WingButton 12×3.5×1.5 мм, CloverButton 11×8×1.5 мм. Компоновка —
по иллюстрации из того же PDF: круглая CloverButton на малоберцовой кости с узлом поверх, WingButton
на большеберцовой, две петли (4 нити) через кость.

| Файл | Треуг. LOD0 / LOD1 | Вес LOD0 / LOD1 |
| --- | --- | --- |
| `dist/cwingbutton_*` | 25 888 / 8 848 | 257 / 113 КБ |

Начало координат — центр CloverButton, нити идут вдоль +X на 40 мм (типичная ширина синдесмоза на
уровне фиксации). Длину меняет `SPAN` в `cwing_params.py`.

Построение: пуговицы — SDF → ремеш (`ti_satin`); петли и узел — `tube` по сплайнам (`suture_tracer`).
`./build.sh` — пересборка.

Ограничения: показано установленное состояние (без проводника-иглы из комплекта); узел — стилизованная
спираль, реальная безузловая «удавка» внутри неразличима на этом масштабе.
